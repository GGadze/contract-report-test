# Отчёт по оплате договоров

Программа строит отчёт по договорам и работам подрядчиков на заданную дату: по каждой работе цена, выплачено, осталось оплатить; по каждому договору итоги.

Нужен только Python 3.9+, внешние библиотеки не требуются.

## Запуск

```bash
python3 contract_report.py --date 10.11.2026
```

Другие варианты:

```bash
python3 contract_report.py --date 2026-11-10 --csv-dir out/   # плюс CSV для Excel
python3 contract_report.py --date 10.11.2026 --json            # JSON вместо текста
python3 contract_report.py --date 10.11.2026 --data другая_папка/
```

Дата принимается как `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`. Коды возврата: `0` - готово, `2` - ошибка в данных или в дате (сообщение в stderr).

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

## Что в папке

| Файл | Что это |
|---|---|
| `contract_report.py` | программа (расчёт, вывод, CLI) |
| `tests/` | тесты: проверочная дата, другие даты, копейки, крайние случаи |
| `DECISIONS.md` | принятые решения, варианты и что изменится, если выбор неверен |
| `NOTE_TO_ACCOUNTANT.md` | записка бухгалтеру |
| `sample_output/` | готовый отчёт на 10.11.2026 (текст и CSV) |
| `data/` | исходные данные без изменений |

## Как считается (коротко)

1. Состояние на дату восстанавливается по датам событий, а не по статусам выгрузки.
2. Выплачено = ушедшие платежи минус возвращённые к этой дате. Платежи в очереди (заведены к дате, но деньги ещё не ушли) не считаются.
3. Привязанные к работе платежи идут в её оплату; остальные раскладываются по принятым работам в порядке приёмки, излишек - авансом на ещё не принятые. Отменённые работы не участвуют.
4. Деньги - `Decimal`, точность до копейки.

Подробнее в `DECISIONS.md`.
